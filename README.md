# CSI-DL - CS Insights SFTP Downloader

One-click SFTP downloader for CS Insights data.

## Features
- No command line required
- Auto-creates key.txt if missing
- Recursively downloads all files and folders

## Usage
1. Double-click `CSI-DL.exe`
2. Enter your SFTP username
3. When Notepad opens, paste your private key and save
4. Wait for "Files were downloaded successfully!"

All files download to the same folder as the executable.

## Requirements
- Windows 10 or later (OpenSSH client installed)
- OR download and extract `pscp.exe` to the same folder

## Build from Source
Python, Bat, OpenSSH, Putty  (64-bit, Console mode, Current directory)
